overview

What I
learned.

COMS472 covers the foundational principles of artificial intelligence, from intelligent agent design to advanced search and decision-making strategies. Using Artificial Intelligence: A Modern Approach (4th edition) as the primary text, the course builds from basic search algorithms through constraint satisfaction and adversarial reasoning to planning under uncertainty.

Key emphasis areas include uninformed and informed search (BFS, DFS, A*), local search methods (hill climbing, simulated annealing, genetic algorithms), handling non-deterministic actions, and reasoning with partial percepts and sensorless problem formulations.

highlights

Key
topics.

Search Algorithms
Implemented and compared uninformed (BFS, DFS, iterative deepening) and informed (A*, greedy best-first) search strategies for problem solving.
Local Search & Optimisation
Explored hill climbing, simulated annealing, and genetic algorithms for optimisation problems where the path doesn't matter — only the goal state.
Non-Deterministic Actions
Studied AND-OR search and contingency planning for environments where action outcomes are uncertain or non-deterministic.
Partial Observability
Tackled belief-state search and sensorless problem formulations where the agent must reason about what it cannot directly observe.
