## AI Definitions: Thinking vs Acting and Humanly vs Rationally

- Internal Thought Process (Thinking)
- External Thought Process (Acting)

## Acting Humanly: Turing Test

- Goal: Make machines behave like humans
- Computer, Interrogator, Human Responder

### Capabilites to pass the Turing Test

- **Natural Language Processing (NLP)** to communicate in a human language.
- **Knowledge Representation** to store what it knows.
- **Automated Reasoning** to answer questions and to draw new conclusions.
- **Machine Learning** to adapt to new circumstances and to detect patterns

Total Turing Test requires interaction with the real world.

## Rational Agent

- "The right thing" is defined by the objective that we provide to the agent
  - Standard model
  - Also used in control theory, operations research, statistics and economics.
- Challenges:
  - Value alignment problem: Specifying the objective completely and correctly.
  - But each human needs different objectives; how to set a universal solution? Specifying the objective is the hard part.
