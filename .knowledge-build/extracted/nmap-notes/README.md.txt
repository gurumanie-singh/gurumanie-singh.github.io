# NMAP Basics Guide

A consolidated reference guide covering core Nmap scanning techniques, flag explanations, and command usage for penetration testing and network enumeration practice.

---

## 🛠 Topics Covered

1. **Host Discovery**  
   - Ping sweeps, ARP discovery, and techniques for identifying live hosts.

2. **Port Scanning**  
   - TCP connect, SYN stealth, UDP, and other scan types with trade-off analysis.

3. **Service & Version Detection**  
   - Banner grabbing and version probes to identify running services.

4. **OS Fingerprinting**  
   - Techniques for determining the target operating system remotely.

5. **Nmap Scripting Engine (NSE)**  
   - Using NSE scripts for vulnerability scanning, brute-force testing, and advanced enumeration.

---

## 🚀 Use Cases

- Penetration testing reconnaissance
- CTF competition quick reference
- Network audit and inventory
- Vulnerability assessment
