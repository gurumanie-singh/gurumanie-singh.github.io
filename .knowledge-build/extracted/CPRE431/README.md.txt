# CPRE431: Basics of Information System Security

Welcome to the CPRE431 repository! This course introduces mechanisms for protecting information systems from both accidental and intentional threats, combining security theory with practical hands-on labs.

---

## 🛠 Core Topics

1. **Cryptography**  
   - Symmetric and asymmetric encryption, hashing algorithms, and digital signatures.

2. **Authentication & Access Control**  
   - Password-based authentication, multi-factor methods, and access control models (DAC, MAC, RBAC).

3. **Malicious Code**  
   - Virus, worm, and trojan analysis; detection techniques and mitigation strategies.

4. **Network Security**  
   - Firewalls, intrusion detection systems (IDS), SSL/TLS, and VPN fundamentals.

5. **Wireless, IoT & Cloud Security**  
   - Security challenges in wireless networks, IoT devices, and cloud environments.

6. **Ethics & Legal Issues**  
   - Responsible disclosure, cyber law, and ethical frameworks for security professionals.

---

## 🔍 Labs & Homework

- **Module 1–8 Homework**: Theory assignments covering each module's security domain.  
- **Lab — Encrypted Attachment Analysis**: Computed MD5 hashes with OpenSSL, decrypted password-protected archives, and recovered plaintext from encrypted files.  
- **Lab — Password Cracking**: Identified hash types and salts from `/etc/shadow`, then cracked user passwords using appropriate tools.  
- **Lab — Slowloris DoS Experiment**: Reproduced a Slowloris denial-of-service attack on an isolated CloudLab slice.  
- **Lab — iptables Firewall Rules**: Created and tested firewall rules to filter traffic and control service accessibility.

---

## 🚀 Learning Outcomes

- Apply cryptographic tools and workflows for encryption and decryption tasks.  
- Understand password hashing, salting, and practical recovery techniques.  
- Configure firewalls and intrusion detection systems.  
- Reproduce and defend against common network attacks in controlled environments.  
- Document security findings in clear, professional technical reports.
