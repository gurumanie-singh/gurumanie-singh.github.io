2. What is the device (interface) named `lo` used for? Use manual pages or 
search online. What address is assigned to the device? 
The device (interface) named `lo` is called a loopback address and it is a reserved IPv4 
address range 127.0.0.0/8. The loopback interface usually uses the first address 127.0.0.1 
in this range. A loopback interface is a virtual interface and does not represent any 
hardware devices. It is just part of the internal TCP/IP stack of the OS. Our machine can 
use this interface to communicate with itself, and it’s very useful in troubleshooting and 
diagnostics. The key purpose of the loopback address is to help in troubleshooting 
scenarios where we want to isolate and identify if a network issue is caused by an internal 
problem inside the machine network stack itself.

7. Perform another traceroute to google.com using TCP packets instead of ICMP. 
Are there any differences in the output? (Hint: sudo is required for 
tcptraceroute)

The key difference between the traceroute command we ran, and the sudo tcptraceroute is 
the routers may be configured to drop/not respond to specific packets (namely our ICMP 
packets). However, when we use sudo tcptraceroute, our packets being used are now TCP 
SYN packets instead of ICMP packets. We can notice that there are less asterisks when 
using TCP packets instead which goes to show that our ICMP packets were being dropped 
by some routers.
