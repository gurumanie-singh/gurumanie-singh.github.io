# CPRE489: Computer Networks

Welcome to the CPRE489 repository! This course provides a comprehensive bottom-up exploration of computer networks, covering the physical, data-link, network, and transport layers with hands-on protocol implementation labs.

---

## 🛠 Core Topics

1. **Physical Layer**  
   - Signal encoding, modulation, multiplexing, and transmission media characteristics.

2. **Data-Link Layer**  
   - Medium access control (ALOHA, CSMA/CD, Token Ring), framing, and error detection (CRC, checksums).

3. **Network Layer**  
   - IP addressing, ARP, DHCP, subnetting, and routing algorithms for end-to-end packet delivery.

4. **Transport Layer**  
   - TCP and UDP, reliable data transfer, flow control, congestion control, and sliding-window protocols.

5. **Error Detection & Recovery**  
   - CRC computation, checksum verification, ARQ protocols, and retransmission strategies.

---

## 🔍 Labs

- **Lab 1 — Networking Utilities**: Explored networking command-line tools for connectivity testing, DNS resolution, and route tracing.  
- **Lab 2–4**: Progressive exercises covering socket programming, packet construction, and protocol analysis.  
- **Lab 5 — Go-Back-N Protocol**: Implemented a GBN reliable transfer protocol with sliding window management, cumulative acknowledgements, timeout-based retransmission, and in-order delivery guarantees.

---

## 🚀 Learning Outcomes

- Understand networking fundamentals across all layers of the protocol stack.  
- Implement reliable data transfer protocols from scratch.  
- Analyse medium access control trade-offs and error recovery strategies.  
- Configure IP addressing, ARP, and DHCP in networked environments.
