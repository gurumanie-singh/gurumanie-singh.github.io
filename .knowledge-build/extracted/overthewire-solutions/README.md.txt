# OverTheWire Solutions Guide

Step-by-step walkthroughs for the OverTheWire Bandit wargame, sharpening Linux command-line skills through progressively challenging security puzzles.

---

## 🛠 What's Covered

Detailed write-ups for **Bandit Levels 0–13**, each including:
- **Level goal** explaining the challenge
- **Step-by-step solution** with exact commands and reasoning
- **Key command summary** for quick reference

---

## 🔑 Skills Demonstrated

- SSH connections with custom ports and key-based authentication
- File system navigation and hidden file discovery
- Text processing with `grep`, `sort`, `uniq`, `tr`, and `strings`
- Base64 decoding, Rot13 ciphers, and hexdump analysis
- Multi-layer compression and decompression (gzip, bzip2, tar)
- File attribute filtering by size, ownership, and type
- SSH key-based login and secure file transfer
