# CPRE532: Information Warfare

Welcome to the CPRE532 repository! This graduate-level course examines offensive and defensive cyber operations, covering adversarial thinking, threat intelligence, reconnaissance, authentication attacks, and web security.

---

## 🛠 Core Modules

1. **Introduction to Adversarial Thinking**  
   - Attacker motivations, kill-chain models, and threat actor profiling.

2. **Cyber-Enabled Adversary**  
   - Nation-state cyber capabilities, APT group tactics, and the role of cyber operations in geopolitical conflict.

3. **Ethics & Network Fundamentals**  
   - Ethical frameworks for offensive security and foundational networking concepts for attack analysis.

4. **Reconnaissance**  
   - Passive and active techniques — OSINT gathering, DNS enumeration, port scanning, and service fingerprinting.

5. **Authentication**  
   - Authentication attack surfaces, credential-based attacks, and defensive countermeasures.

6. **Web Security**  
   - Common web application vulnerabilities, exploitation techniques, and secure development practices.

---

## 🔍 Labs & Homework

- **Lab 1–3**: Practical exercises applying reconnaissance, authentication analysis, and web application testing methodologies.  
- **Homework 1, 3, 4**: Written assignments deepening understanding of strategic and tactical cyber operations.  
- **Module notes**: Detailed study notes for each module covering adversarial thinking through web security.

---

## 🚀 Learning Outcomes

- Analyse cyber threats from both offensive and defensive perspectives.  
- Apply reconnaissance techniques and assess authentication attack surfaces.  
- Evaluate web application security posture and recommend mitigations.  
- Reason about ethical and legal dimensions of cyber operations.
