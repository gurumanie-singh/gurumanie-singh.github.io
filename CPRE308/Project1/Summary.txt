With this project I learned how to build a functional UNIX shell from scratch using fundamental system calls and process management in C. I was able to gain some more practical experience with fork() and execvp() apart from the labs while also understanding how the operating system creates child processes and replaces them with new program images. I also got a deeper understanding of how to handle command parsing by tokenizing the input and managing command-line arguments. Additionally, I implemented some built-in commands that directly manipulate the shell's state. For example, changing directories with chdir() and retrieving process information with getpid() and getppid(). This project reinforced my understanding from the labs and lecture materials of how a shell works at a lower level and the distinction between built-in commands and external programs.

I think that the most interesting lesson was learning process management and how to handle multiple processes effectively. I implemented background process execution using the & operator and learned how waitpid() with the WNOHANG flag allows the shell to check for the finished background processes without blocking. I also learned how to properly handle a process's exit status using the status macros like WIFEXITED() and WEXITSTATUS(). Furthermore, through some amount of debugging and testing, I found out the importance of error handling with perror() and ensuring that system calls return successfully before proceeding. Overall, this project gave me a deeper understanding of how operating systems manage processes and how shells provide the interface between users and the operating system.
