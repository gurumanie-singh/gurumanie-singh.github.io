# CPRE308: Operating Systems

Welcome to the CPRE308 repository! This course covers core operating system concepts — processes, threads, synchronisation, scheduling, deadlock handling, memory management, and file systems — with practical Linux-based lab experiments.

---

## 🛠 Core Topics

1. **Processes & Threads**  
   - Creation, lifecycle management, and inter-process communication mechanisms.

2. **Synchronisation**  
   - Mutexes, semaphores, race conditions, and critical section design patterns.

3. **Scheduling**  
   - Process and thread scheduling algorithms with performance trade-off analysis.

4. **Deadlocks**  
   - Detection, prevention, and avoidance strategies (Banker's algorithm, resource ordering).

5. **Memory Management**  
   - Paging, segmentation, virtual memory, and allocation strategies.

6. **File Systems & I/O**  
   - File system internals, I/O subsystem design, and device driver interfaces.

---

## 🔍 Labs & Projects

- **Lab 1–8**: Progressive exercises covering process creation, shell programming, threading, synchronisation primitives, memory management, and file system operations.  
- **Project 1 — Custom Shell**: Built a Unix shell in C supporting command parsing, process forking, I/O redirection, and signal handling.  
- **Project 2 — Locking Granularity**: Compared fine-grained, medium-grained, and coarse-grained locking strategies in multithreaded programs, measuring performance and contention effects.

---

## 🚀 Learning Outcomes

- Implement concurrent programs using POSIX threads and synchronisation primitives.  
- Analyse trade-offs between concurrency and correctness.  
- Design and evaluate scheduling and memory management policies.  
- Build system-level software (shells, threaded servers) in C on Linux.
