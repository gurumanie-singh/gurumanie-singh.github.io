# COMS311: Design and Analysis of Algorithms

Welcome to the COMS311 repository! This course covers the fundamental principles and techniques for designing and analysing algorithms, from classic sorting and graph traversal to NP-completeness theory.

---

## 🛠 Core Topics

1. **Algorithm Design Paradigms**  
   - Divide and conquer, greedy methods, dynamic programming, and approximation algorithms.

2. **Graph Algorithms**  
   - DFS, BFS, shortest paths (Dijkstra, Bellman-Ford), and network flow.

3. **Complexity Analysis**  
   - Asymptotic, worst-case, average-case, and amortised analysis techniques.

4. **NP-Completeness**  
   - Introduction to computational complexity, problem reducibility, and NP-hard problems.

5. **Advanced Data Structures**  
   - Balanced trees, hashing, and string matching algorithms.

---

## 🔍 Assignments & Projects

- **Homework 1–5**: Theory-based problem sets covering algorithm design, recurrence relations, graph problems, and complexity proofs.  
- **Coding Assignment — DFS Graph Analyser**: Implemented Depth-First Search from scratch to analyse graph connectivity and traversal efficiency.  
- **Coding Assignment — Network Analyser**: Designed a graph-based tool to identify and evaluate critical links using algorithmic efficiency principles.

---

## 🚀 Learning Outcomes

- Translate theoretical algorithm designs into optimised, maintainable code.  
- Analyse time and space complexity using multiple analytical frameworks.  
- Select appropriate data structures based on performance trade-offs.  
- Recognise and reason about NP-complete problems and approximation strategies.
