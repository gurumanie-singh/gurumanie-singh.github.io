Frosted Glass Terminal Theme

A sleek, semi-transparent MacOS Terminal theme inspired by Hyper's Verminal aesthetic — featuring Monaco font, frosted blur, and a vibrant color palette for daily terminal use.

Installation Guide

  1. Download FrostedGlass.terminal using the button above.
  2. Double-click the file to import it into your MacOS Terminal app.
  3. Go to Terminal → Settings → Profiles and select "Frosted Glass".
  4. Click Default to make it your default terminal theme.
  5. Restart Terminal to apply the new theme.

Recommended Fonts

  • Monaco (default and pre-configured)
  • Jetbrains Mono (alternative)
  • SF Mono (macOS system fallback)
